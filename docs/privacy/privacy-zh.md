# 隐私政策

**应用名称**：PalmNote（掌记）
**最后更新**：2026年10月18日

PalmNote 是一款纯本地应用。这份说明只想讲清楚一件事：**你的数据不离开你的设备。**

## 一、我们不收集数据

不收集。PalmNote 在清单中以 `tools:node="remove"` 移除了网络权限（INTERNET），
在系统层面就没有联网能力，因此不存在上传、回传或遥测。应用内没有广告、统计或崩溃上报 SDK，
也不提供账号注册——没有服务器可言。

## 二、你主动使用功能时，在本机处理的数据

- **账单导入**：通过系统文件选择器选中你下载的账单文件，解析全程在本机离线完成，文件不外传
- **应用锁**：PIN 经加盐哈希后存储；指纹 / 面部仅用于本机校验，不存储、不上传
- **日历同步**：仅在你开启后写入系统日历，不读取其它日历数据

## 三、数据存在哪里

全部存放在应用私有目录（`/data/data/com.palmnote/`），受 Android 沙箱保护，其它应用无法读取：

- **数据库**：SQLCipher 全库加密（AES-256），密钥仅存于本机
- **备份文件**：可选 AES-GCM 加密，密钥由你设定
- **密码本**：字段级加密，独立主密码

## 四、你的数据你做主

你可以随时导出备份、删除单条或全部数据。卸载应用即彻底删除本机全部数据，且不可恢复。
