# 生活页 v2.0 —— 执行闭环改造方案(定稿)

> 状态:定稿
> 目标:将生活模块从"规划工具"升级为"规划 → 执行 → 反馈"闭环,以今日看板为核心,突出坚持 / 打卡 / 进度反馈。
> 版本:2026-08-15 · v2.0

---

## 一、方案总览

### 1.1 核心问题

- 生活模块已有 **16 个模板专属页面**(存钱/阅读/购物/学习/订阅/旅行/待办 + 专注/习惯/日记/心情/周报 + 纪念/生日/倒计时/正数日),互不相通,缺统合视角。
- 只做"记录",不做"执行"。计划建完没有按日触发、没有打卡闭环、没有进度反馈。

### 1.2 解决思路

以 `LifeItem.dueDate` 单索引列为聚合键,建立今日看板;赋予 LifeItem 执行列(重复/子任务/提醒),形成"勾选 → 看板聚合 → 自动完成 → 归档"的闭环;用轻量动态分类 + 可配置分类卡满足用户自定义组织诉求。

### 1.3 决策锁定表

| 维度 | 决定 |
|---|---|
| 旧 16 页 | **逐步迁移**到通用字段/卡片系统(替换专属 Screen) |
| 里程碑 | **简化**=带 dueDate 的子任务,复用 LifeItem,无 meta.JSON 引擎 |
| 动态分类 | **保留**:Chips+自由输入 → 已有 `category` 列,零迁移,无管理 UI |
| IMAGE 字段 | **延后**:仅保留现有占位,真图片跳3随迁移接入 |
| 分组根修 | 只信 `category` 列(`LifeViewModel.kt:112-114`),删英文+name 兜底;三分类平移「计划→目标 / 时间→纪念 / 记录→记录」 |
| 分类卡交互 | 照搬 app 主页 Dashboard 拖拽方案(长按拖 + 300ms 防抖持久化) |
| 完成态 | 零新增 UI:全勾→降透明归档/过期末→归档;无庆祝横幅/摘记框/复制计划 |
| 快速添加 | 不设输入条,新建一律走右下角 FAB |

### 1.4 范围

**做**:今日看板 / LifeItem 执行列(迁移7→8)/ 字段枚举对齐(CURRENCY/DATETIME/RICH_TEXT/FILE)/ 分组根修 / 轻动态分类 / 分类卡可配置(形态切换+拖拽排序)/ RichCard / 统计页 / 分类详情页×3 / 旧页面逐步迁移 / 里程碑简化 / 完成态零新增 UI。

**砍**:模块化主页 / 卡片市场 / AUDIO+SIGNATURE / 拖拽调位(仅分类区保留)/ 里程碑引擎 / 计划树按日派生双显 / 快速添加条 / IMAGE 真实现(本轮)。

### 3.3.2 今日看板概念定义(分界)

> **今日看板 = 今天要做的事(计划/待办/习惯打卡)+ 今天要知道的(纪念/里程碑/倒计时/订阅到期)+ 今天记录的(日记/心情/专注/新增记录)。**

三张分类卡(目标/纪念/记录)= 三类别归属,定义与分类卡天然对齐。

| 条目 | 归属 | 依据 |
|---|---|---|
| `dueDate` = 今天(待办 or 计划子任务) | 今日看板时段槽 | 今天要做 |
| 习惯打卡(Goal) | 今日看板时段槽旁路入口 [打卡] | 今天要做 |
| 纪念到期 / 里程碑到期 / 倒计时 / 订阅到期(今天) | 今日看板时段槽 | 今天要知道 |
| 记录类条目今日新增(日记/心情/专注/新增) | 今日看板·今日记录区 | 今天记录 |
| 待办模板 且 非今天 且未完成 | **待办卡**(3.3.1,补集) | 堆积待办,不进看板 |
| 计划模板 且 非今天 | 计划页 / 分类详情页 | 计划闭环,不进待办卡 |

### 4.2 Migration 7 → 8

- AppDatabase version 7 → 8。
- 全部新列 **可空 ADD COLUMN**,一列一条,顺序无关,无数据回填。
- 索引:`CREATE INDEX IF NOT EXISTS idx_items_due ON life_items(dueDate)`。
- **必须新增** `Migration7To8Test`(case:空库 + 7 数据库升级后新列存在/旧数据完好)。
